# One Shot Slice Fix - Practice Landing Page

A static HTML/CSS/JS clone of a golf product landing page, built for learning and editing practice.

## Getting Started

1. Clone this repo: `git clone https://github.com/YOUR_USERNAME/one-shot-slice-fix.git`
2. Open `index.html` in your browser
3. Edit any file and refresh to see changes

## Customization

- **Images**: All images currently link to external CDN URLs. Replace them with your own by saving images to the `images/` folder and updating the `src` attributes in `index.html`. Search for `<!-- IMAGE: -->` comments to find every image.
- **Colors**: Edit CSS custom properties in `css/styles.css` under `:root`
- **Content**: Edit text directly in `index.html`
- **Layout**: Modify the CSS grid/flexbox rules in `css/styles.css`
